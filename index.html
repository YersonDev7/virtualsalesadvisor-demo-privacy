VirtualSalesAdvisor Demo

Privacy Policy

Last updated: November 11, 2026

Development and testing only. VirtualSalesAdvisor Demo is an experimental application developed to test integration with the WhatsApp Business Cloud API. It is not a production customer service channel.

1. Information We Process

During authorized testing, the application may process the following information:

  • WhatsApp phone numbers of test participants.
  • Messages sent during test conversations.
  • WhatsApp message identifiers and message types.
  • Technical timestamps and diagnostic information.
  • Test account associations used to authorize participants.

2. How Information Is Used

Information is processed exclusively for development, testing, and troubleshooting purposes, including:

  • Testing WhatsApp Cloud API connectivity.
  • Receiving and sending test messages.
  • Verifying authorized test participants.
  • Diagnosing technical errors.
  • Evaluating automated messaging functionality.

3. Information Storage

The application may store authorized test phone numbers and their associated test accounts in its database.

Technical logs may contain message identifiers, message types, timestamps, and information required to diagnose integration failures.

The current webhook implementation does not intentionally persist incoming message text in its application logs. Message content may be processed in memory during testing.

4. Information Sharing

The application communicates with Meta's WhatsApp Cloud API to exchange messages. Relevant information is processed by Meta according to its applicable terms and policies.

Technical infrastructure providers may process information necessary to operate the demonstration and deliver requests.

Personal information is not sold or used for advertising purposes by this demonstration.

5. Data Retention

Test information is retained only as needed for development, testing, troubleshooting, or applicable legal requirements. Data that is no longer required will be deleted or anonymized where technically feasible.

6. Data Security

The demonstration uses technical controls intended to protect API credentials and validate incoming webhook requests. Access to application resources is restricted to authorized development and testing activities.

7. Data Deletion Requests

Test participants may request access to or deletion of personal information controlled by this application.

To submit a request, contact: programacion@laminaire.net

Include enough information to identify the relevant test account or WhatsApp number. Do not send passwords, access tokens, or confidential message content.

Requests will be reviewed and applicable data controlled by the demonstration will be removed where technically feasible and legally permitted. Data independently held by Meta is subject to Meta's own policies.

8. Third-Party Services

The demonstration uses the WhatsApp Business Cloud API provided by Meta. The privacy practices of Meta are governed by its own policies.

This privacy policy page is hosted using GitHub Pages.

9. Changes to This Policy

This policy may be updated as the demonstration evolves. Changes to the processing of personal information will be reflected in an updated version of this document.

10. Contact

For privacy questions or data deletion requests, contact: programacion@laminaire.net
